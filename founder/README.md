# founder/ — GFC Xtreme working folder

The Founder skill pack (11 skills) is installed at `.claude/skills/founder-*`
and runs as `/founder-board`, `/founder-cfo`, `/founder-consumer`, etc.

```
board -> competitors -> consumer -> pricing -> offer -> cfo -> marketing -> brand -> ops -> launch -> plan
```

## The model

1:1 online coaching, founder-delivered, leveraged by app + async check-ins.
$300/client-month, **30 clients by month 12**. The founder's labour sits in
`fixed_monthly` as a draw, not in `variable`, because it is a capacity limit
rather than a cash cost per sale.

Current verdict (`compile.py --check`): **Not yet** — 93% contribution,
break-even 21 clients, but a 30-client roster crosses that line only in month 7,
so year 1 loses $10,575 and the startup spend is not earned back.

At a capped roster, price is the only lever left. $400 turns year 1 positive
(+$10,594); $500 pays the startup back in month 10 (+$31,762). See
`scenarios30.txt`.

## What the pack does not model

`unit_economics.py` assumes a transaction business. A monthly retainer has two
numbers it has no input for, and they set the real ceiling:

- **churn** — a roster is a leaky bucket: steady state = new per month / churn
- **CAC** — replacing churn costs money before any growth happens

`retention.py` adds that layer. Without it the sweep returns roster sizes no
solo coach could ever hold.
